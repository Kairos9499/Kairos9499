# Привет, меня зовут Паша 👋

### 👨‍💻 Обо мне:

Занимаюсь разработкой микросервисных приложений на языке Go (Golang). Ещё в школе я начал интересоваться информатикой и программированием, поэтому пошел учиться в университет на программиста, и получил высшее образование по специальности "Информатика и вычислительная техника". Сейчас я обладаю следующими навыками:

- 🚀 **Go:** разработка веб-серверов и бэкенда, обработка HTTP-запросов;
- 🗂️ **Базы данных:** работаю как с SQL (PostgreSQL, SQLite), так и NoSQL (Redis) СУБД;
- ⚙️ **Клиент-Серверные Архитектуры:** Разработка и поддержка TCP-соединений, горутин, каналов и мьютексов для эффективной коммуникации между сервером и клиентами;
- 🔧 **Разработка API:** проектирование и создание серверных приложений с REST API;
- 🐳 **Docker:** упаковка приложений в образы, запуск мульти-контейнерных приложений;
- 🌐 **Веб-разработка**: адаптивная верстка и оживление интерфейсов (HTML, CSS, JavaScript).
-  **Другое:** дополнительно я изучал C, C++, C#, PHP, Python, Assembler.
